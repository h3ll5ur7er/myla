Build from source

The repository carries the compiler as assembly (the seed) for each machine, so all it needs is GNU as and ld.

git clone {{ repo }}
cd myla
scripts/bootstrap.sh      # stages 0 to 3 and the fixed point; writes build/myla
build/myla run examples/hello.my

Then the quickstart shows the commands and projects, and the course the language.
