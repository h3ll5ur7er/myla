`render_arg` in [[selfhost/codegen.my]] (around line 2586) has no `TChar` or `TFloat` arm, so the value is used as a string pointer. `format("{}", 'a')` and `f"{c}"` with a `char` crash.

## Done when

- [x] `TChar` renders through `__char_to_str` (the self-hosted runtime had none; it now embeds the Python backend's, generated by `scripts/gen_selfhost_runtime.py`)
- [x] `TFloat` renders through `__float_to_str` ([[MYLA-29]]); both covered by the parity program `floats_in_depth`, also run through the self-hosted compiler
- [ ] Differential test
