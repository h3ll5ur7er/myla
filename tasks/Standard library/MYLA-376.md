Wave 3's lanes ([[Project/Standard-library-roadmap]]) couldn't import `std.str`, `std.char`, `std.list` or `std.hash` in a `lib/std` module: its native harness didn't build ([[MYLA-360]]). So they wrote private copies. MYLA-360 is fixed, and these can go:

- [x] `std.text`: the parts of `words`, `pad_start`/`pad_end` (`spaces`, `char_count`) and `join`
- [x] `std.grid`: the test helpers `ok`, `is`, `is_err`, `none`; `std.graph`: `has`
- [x] `std.bitset`: SWAR `ones`, `highest`, `lowest`. They need a `count_ones`/`trailing_zeros` in `std.int` first, which it doesn't have
- [x] `std.compress`: `crc32_part`, `adler32_part` (`std.hash`, or [[MYLA-359]]'s checksum module)
- [x] `std.bigint`: `filled`, and loops instead of `extend`
- [x] `std.btree`: `inserted`, `removed`, `key_or`, `value_or`
- [x] `std.fs`: `bytes_of`, `text_of`, `hex_of`, `joined`, `root_of`
- [x] `std.path`, `std.glob`: wave 2's ([[MYLA-326]])
- [x] Each module's cases still pass interpreted and with `--native`, and their measurements don't get worse

Wave 4's modules (`std.xml`, `std.yaml`, `std.archive`, `std.net`, `std.http`, `std.term`, `std.task`) had the same kind of copies and were done too.

## What changed

The rule: a private helper went where the library has the same thing, it behaves the same and it isn't slower in a hot path; it stayed, with a comment saying why, where it differs, where it works around a language limit, or where the import costs a lot for little.

- **std.int** (generated by `scripts/gen_std_int.py`): `count_ones`, `leading_zeros` and `trailing_zeros` on every width, returning `int`; a negative number's bits are its two's complement's; `leading_zeros` and `trailing_zeros` of 0 are the width. 216 cases from Python's integers (2042 in all). `count_ones` and `trailing_zeros` are SWAR and branch-free; `trailing_zeros` has the popcount written out, as a method isn't inlined.
- **std.fs** exports `io_error_name(e: IoError) -> str` (`"NotFound"`, `"Other(9)"`), and std.compress, std.archive and std.http use it for their copies of the table (`io_name`), as do std.fs's tests (`error_name`). `IoError` still has no `Format` ([[MYLA-379]]). `bytes_of`/`text_of` are std.bytes's `from_str`/`to_str`.
- **swapped:** std.text (`words`, `join`, `pad_start`, `pad_end`; `spaces`, `char_count` gone); std.grid (`filled`, `extend`, `map`; tests `is_none`, `err`); std.graph (`filled`, `reversed`, `contains`); std.bigint (`filled`, `extend`); std.btree (`insert`, `remove_at`, `extend` for `inserted`, `removed` and the merge loops; tests `==`, `is_none`, `map`/`unwrap_or`); std.path (`join`); std.glob (`sorted_by`, `dedup`, `join`); std.compress (`filled` for `zeros`/`run_of`, `from_str` for `text`); std.archive (`from_str`, `to_str`, `contains`, `filled`); std.net (`from_str`, `to_str`, `find`/`find_from` for `find_byte`, `to_lower`, `contains`); std.http (`format("{:x}")` for `hex`, `to_str` for `of_bytes`); std.term (`concat`, `remove_at` for `spliced`); std.task (`extend`; tests `map`, `join`, `is_none`); std.xml and std.yaml (`to_digit` for their digit helpers, `format("{}", c as char)` for their UTF-8 encoders, yaml's `{:02x}` for `hex2`).
- **kept, and why:**
  - std.bitset's `ones`, `highest`, `lowest` and std.bigint's `leading_zeros`: a module of std that imports std.int makes every program importing it parse std.int's 2042 cases. The loader loads the entry's imports before the implicit modules, which it loads with their cases skipped unparsed; a module reached first through an explicit import keeps them. A hello world importing std.bitset took 58 ms to check instead of 46 (CPU time, best of 11); with std.int's case lines removed the import cost 1 ms. And only a function of the module itself is inlined (`ones` is, in `popcount`; `count_ones` was a call per word).
  - std.compress's `crc32_part`/`adler32_part`: std.hash's checksums take a whole list and make the CRC's tables at each call; slicing the decoder's output for them took `gunzip` of 100 MB from 526 to 802 ms (the slice alone: 771 ms), and `gzip_reader` read 16 KiB at a time from 663 to 868 ms.
  - std.btree's leaf shift (both lists in one loop): `insert` on each took a million inserts from 320 to 360 ms.
  - std.fs's `hex_of` (std.encoding would be checked by every program using std.io, for one function of 9 lines), `joined` (std.path's `join` gives an absolute name as it is, and would bring std.path and slices into std.fs), `root_of` (nothing in std trims slashes but the root's).
  - std.grid's `is`, std.btree's `is_some_of` and `same_*`: an `Option` has no `==`; std.grid's `ok`: `expect` wouldn't show the error.
  - std.text's byte tests (`ints` calls them for every byte; std.char's are methods on `char`, not inlined); std.glob's `split` (std.str's `split` and a filter make two lists for each path matched).
  - std.archive's and std.compress's test `unhex` (std.encoding would be checked by their importers for the tests' sake); std.net's test `hex_of`/`unhex`, likewise.
  - std.net's `fields` (spaces, tabs and CRs, not all whitespace as `words`), `lines` (drops comments), `tail_of`; std.http's `part`, std.term's `part`, std.xml's `piece` (a part of a string that may end inside a character, [[MYLA-390]]); std.http's `find_byte` (the parser's per-line search), `trim_ows` (spaces and tabs only), `same_name` (ASCII case without two new strings), `lossy_utf8`/`utf8_length` (std.bytes checks UTF-8 in a `[uint8]`, which a body would be copied into); std.term's `text_of` (nothing in std makes a string of a `[char]`); std.xml's `starts_at`/`is_cut` (std.str has no match at an offset), its whitespace (XML's four characters) and its in-place UTF-8 decoding; std.bigint's `fill_to` (std.fmt's is private).

## Evidence

- **Hot paths**, natively, the same compiler with the library before (81fe44e) and after, the binaries run alternately, best of each run's repetitions, median (and min) over 7 to 9 runs. The machine was shared (load 4 to 5 on 4 CPUs), so runs varied by ±5 %:
  - `std.text`'s `ints` on 10 MB (2,311,236 integers): 55 → 53 ms (min 53 → 52); its code is unchanged.
  - `std.compress`'s `gunzip` of 100 MB (13 MB of gzip, the repository's sources): 561 → 560 ms (min 551 → 547); `gzip_reader`, 16 KiB reads: 720 → 717 ms.
  - `std.bigint`'s 10,000 × 10,000 digit product: 774 → 786 µs, 802 → 830 µs and 769 → 768 µs in three rounds; callgrind counts 1,924,199,242 instructions before and 1,924,880,841 after (+0.04 %).
  - `std.btree`'s 1M inserts: 331 → 320 ms and 349 → 347 ms (in-place inserts in splits and merges).
  - `std.bitset`'s sieve to 20M: the module's code is as before; 234 → 234 ms. With `count_ones`/`trailing_zeros` it measured 206 to 240 ms against 219 to 226 depending on the build: callgrind showed the same instructions (15.116 G against 15.124 G) and 80 % of them in the unchanged `remove`, whose address the change moved; the word loops alone (`popcount` ×10, `items`, `next_from`) were 28 → 30 ms, a call per word.
- **Check time** of a hello world importing each module (CPU time of `myla check`, min of 15 runs, the runs alternating; noise about ±3 ms), before → after: none 45.6 → 47.9, text 72.7 → 77.4, grid 50.1 → 53.8, graph 61.9 → 63.7, bitset 52.8 → 54.1, compress 106.9 → 110.4, bigint 78.3 → 83.4, btree 58.9 → 62.1, fs 58.0 → 63.4, path 48.6 → 50.2, glob 75.7 → 80.5, xml 98.0 → 98.7, yaml 90.8 → 95.6, archive 128.7 → 131.9, net 103.6 → 107.6, http 186.5 → 189.5, term 98.7 → 105.1, task 56.2 → 58.8 ms. About 2 ms of each is std.int's new methods, which every program checks (only std.int swapped: 43.8 → 48.3 and 43.6 → 46.8, min of 21); std.fs's std.bytes import measured -0.4 ms against the private helpers.
- **Cases**, interpreted and `--native`, every changed module: text 139, grid 13, graph 9, bitset 73, compress 136, bigint 140, btree 8, fs 65, path 92, glob 51, xml 90, yaml 126, archive 83, net 93, http 156, term 100, task 31, int 2042, all passing (the counts fall by the removed helpers' own cases). `--target aarch64-linux` (qemu) and `--target wasm32-wasi` (Node, `MYLA_EMULATOR="node tools/wasm/run.mjs"`): fs, net, http, term, glob, archive and compress pass on both.
- `scripts/test.sh fast`: 711 tests, one failure, `test_embedded_std` (`selfhost/embedded_std.my` isn't what `lib` gives), as the seed and the embedded library are left to the pull request's last commit (D156). `python3 -m unittest tests.burn.test_std_modules tests.burn.test_doc_blocks tests.burn.test_compress tests.burn.test_archive tests.burn.test_fs tests.burn.test_net tests.burn.test_http tests.burn.test_xml tests.burn.test_yaml tests.burn.test_term`: 73 tests, OK (4 skipped); `test_imported_cases`, `test_implicit_imports` OK.
- `scripts/bootstrap.sh` (std.fs and std.term are the compiler's): byte-identical fixed point, 18,150,219 bytes.
- `python3 scripts/gen_std_int.py --check`: current.

Follow-up: the loader could load every module but the entry without its cases (`skip_tests` for all of them, not only the implicit ones); then std.bitset and std.bigint could import std.int at no cost.
