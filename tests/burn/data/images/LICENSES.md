# The image and font corpus: sources and licences

MYLA-945. `manifest.json` lists every file with its `source`; `python3 -m tests.burn.test_images --vendor` makes the corpus again (`tests/burn/_images_vendor.py`). The fields and the driver protocol are described in `tests/burn/_images.py`.

(c) Willem van Schaik, 1996, 2011" (`png/pngsuite/PngSuite.LICENSE`) |

Digitized data copyright (c) 2010 Google Corporation with Reserved Font Arimo, Tinos and Cousine. Copyright (c) 2012 Red Hat, Inc. with Reserved Font Name Liberation |
| `jpeg/`, `gif/`, `qoi/` | Written by Pillow 13 (libjpeg-turbo 3.2) from synthetic pictures made by `_images_vendor.py` (seeded gradients, noise, blobs, edges); `jpeg/photo-q85-s440.jpg` and `jpeg/photo-q85-s411.jpg` by ImageMagick 6.9; the broken files are good ones edited by the script | Made for this repository; no third-party content. `jpeg/text-q75-s420.jpg` shows text drawn with DejaVu Sans (a picture of text, not font software) |
| `png/gen/`, `tiff/`, `bmp/`, `pnm/` | Written by the script's own encoders from synthetic pictures, each checked against Pillow's decode where Pillow reads the format | Made for this repository; no third-party content |
| `expected/` | The expected pixels as PAM files: Pillow's decode, or the source pictures and `_images.png_decode` where Pillow keeps fewer bits or keeps transparency aside (each entry's `notes` says which), Pillow's renderings of text with Myla Test Sans (`expected/fonts/`, autohinted by FreeType) and unhinted FreeType renderings through freetype-py (`expected/fonts/unhinted/`: glyphs at quarter-pixel offsets, two strings) | Derived from the files above, under their licences |
| `fonts/info.json` | Facts about the font read with fontTools (metrics, kerning pairs, composite glyphs) | Made for this repository |
