## 1. Summary

1. **Round 6 fixed what the last review found.** Every main reproducer of the last bundle now gives the right answer: the closure crash, the use-after-free across operands, the unchecked impl bound, the XML reader's wait, the one-byte HTTP attack, the harness's differing verdicts. Of the 78 tasks, 33 are done, 31 are done with a follow-up, and 14 should be reopened.
2. **Master's CI is red at the reviewed commit.** On the real Windows runner `process/many-children` counted 393 of 400 children (164 cases passed, 1 failed, 1 skipped). The pull request's own run was green, so it is intermittent. It did not reproduce in 54 runs under Wine, and the code swallows the failure in two places, so the run can't say why. Because the job failed, this commit's `myla.exe` was not published.
3. **The new features work on their happy paths and on every runner, and each has a hole at an edge.** The operator traits reopen the type confusion that [[MYLA-538]] closed; a generic `#track_caller` function computes wrong results in the interpreter; `json.decode<Matrix>` accepts a shape with no data; `sinh` and `tanh` are off by up to 74,000 ulps; the router's `static_files` is a directory traversal on the Windows target.
4. **Two older bugs that every runner shares**, found because the reviewers compared against a second expectation instead of runner against runner: in async code `g[i + 1].push(await f())` loses its write, and an `async` method in an `impl Add` is called by `+` from plain code and crashes natively.
5. **Two of the round's gains were given back within days.** [[MYLA-552]] and [[MYLA-608]] brought a hello world's check to 20.7 M instructions; the next commit (the implicit `std.float`, D199) took it to 25.3 M, and `myla run` of an empty program from 24.0 M to 35.7 M. D245's millisecond glance cut I/O beside a yielding task from 98,942 to 499 round trips a second. Nothing in the suite bounds either.
6. **The Windows target is in good shape for its age.** A hello world is a 22 KB static `.exe` that imports only kernel32, with ASLR and NX set; the calling convention checks out by hand; the compiler bootstraps from its Windows seed to the fixed point under Wine and writes the same assembly as on Linux; `std.path` agrees with Python's `ntpath` on 37,704 checks; sockets and HTTP behave as on Linux on 1, 4 and 16 workers.
7. **Baseline.** The bootstrap reaches its fixed point from all three seeds. The full suite: 1,792 tests, 440 skipped, one failure under the reviewers' load (`test_children_run_in_parallel`, which passes alone, as in the last three reviews). `#test` coverage of `selfhost/` fell again, to 61 percent (1,504 of 2,451).

## 4. Decisions for the owner

1. **A folder named `std` in a program.** `Modules.md` says it is an error; it isn't for `from .std.x import`, and it still gets two of the library's privileges (H2) and a build-only collision. Recommended: refuse a root-level `std` folder outright, which closes all three; the alternative is to take every privilege by the loader's root.
2. **`async` on a trait impl's method** (H3). Recommended: refuse it where the trait's method isn't async, for the operator traits and `Eq`, `Ord`, `Hash`, `Format`, until [[MYLA-434]] designs async trait methods.
3. **Who may add an operator impl.** Any module may write `impl Mul<int> for vector.Vec3`, and a second integer impl elsewhere changes how `v * 2` resolves in code that relied on the single one. Recommended: an operator impl lives in the module of its `Self` type or of a type argument, as Rust has it; and state the literal rule on the operators page.
4. **The cost of an implicit module** (M4). Recommended: register `std.float`'s methods lazily (load `std.math` only when a float method is called), and add a test that pins the check's and the start-up's instruction counts, so the next implicit module shows up as a red test and not in a review.
5. **A time limit for a test case.** A spinning case hangs both runners. Recommended: build [[MYLA-547]]'s third proposal (`--timeout`, with a default), and kill the child's process group when the runner dies.
6. **`static_files`' policy** (H8 and the low items): dot files, symlinks out of the root, device names and trailing dots on Windows, a whole file read into memory. Recommended: regular files under the resolved root only, no dot files by default, streamed.
7. **Long paths on Windows.** Nothing adds `\\?\`, so a path past 260 characters should fail on real Windows (unverified). Recommended: prefix as Rust does.
8. **The generated tests' full size.** CI runs a fixed sample (1,500 of 17,497 extreme calls, seed 555). Recommended: a master-only or scheduled step with `MYLA_GENERATED=full` and a seed from the run number.
