## 1. Summary

1. **Every reproducer of the two earlier reviews now gives the right answer** on every runner it names (H1 to H10, the M and L lists, Z1 to Z4, S1 to S5). What is left of those findings are neighbouring cases their reproducers didn't cover (one more shape each for H1, H3 and Z1) and M27's speed, which is fixed by instructions and not by time. 46 of the 52 tasks are signed off, 27 of them with follow-ups; 6 are reopened, each by a narrow fix.
2. **The six reopened tasks** are [[MYLA-414]] (the interpreter loses a type binding in one more place, and its new memo grows without bound), [[MYLA-415]] (a closure that captures a recursive enum still crashes when copied to a task), [[MYLA-417]] and [[MYLA-394]] (D178's new call error rejects a valid program; D95's warning got weaker), [[MYLA-413]] (a program's own `std/` directory is read lazily, so `myla check` says `ok` over its errors) and [[MYLA-460]] (the XML stream reader's fix made it wait for bytes it doesn't need).
3. **Seven high findings.** One came with the round (the XML reader, B4). Four are older and were reached now by generated tests: a crash copying a closure to a task (B1), a use-after-free in native code when a later operand frees what an earlier one read (B2), a type confusion through an unchecked impl bound (B3, [[MYLA-538]], which was filed `low`) and `std.yaml` trapping on a large hex scalar (B5). A fifth older one is the interpreter's lost binding (B6). The seventh was declared by its own task: one byte per socket still stops a default HTTP server (B7).
4. **The numbers hold.** Bootstrap fixed point; seeds 10.9 MB and 25.3 MB (19.4 and 31.5 before); a hello world checks in 21.2 M instructions and 6.1 ms (39.4 M, 8.7 ms), with std.io in 37 M (101 M), with std.http in 146 M (394 M); maps shrink (a drained 10^6-key map: 76 s to 0 ms); the regex engine agrees with Go on 453,790 cases; 480,000 stream commands and 26,155 checked-arithmetic cases agree on every runner.
5. **Baseline**: the full suite is 1,547 tests, 339 skipped, one failure under the reviewers' load (`test_children_run_in_parallel`, which passes alone, as in both earlier reviews). `#test` coverage of `selfhost/` fell from 67 to 63 percent (1,447 of 2,295 functions): the round added 188 functions and 45 tested ones.
6. **What the fixes' tests miss, generated tests find.** Each package pinned one program per reported bug. The reviewers' generators (deep copies over 35 value shapes, 5,400 write statements, 90 read forms, 320 per-width programs, extreme-argument calls) found every older bug below within minutes. [[MYLA-555]] makes them burn tests.

## 4. Decisions for the owner

1. **The test child's report** (C5). Stderr alone can't tell a multi-line panic from an `eprint` followed by a panic. D189 set aside the alternative, a report the runtime marks itself. Recommended: take it up now (a framed record on stderr, written by the runtime only in a test child), which also closes the forged marks and the confusion [[MYLA-418]] declared. Otherwise document the second limit.
2. **Raw mode and signals.** Catch SIGINT, SIGTERM and SIGHUP while the terminal is raw, restore it and end as the signal would. Recommended: yes; D187 says raw mode ends with the program, and Ctrl-C is the commonest way a terminal program ends.
3. **`place[i()].push(v())`** (C9). Recommended: the receiver's place first, then the arguments, as the interpreter does and as every other method call does; native code changes.
4. **A recursive enum as a map key** (C11). Recommended: build it, as the interpreter does (D163: every `Eq + Hash` type is a key). The alternative is a checker error with a real message.
5. **`Notifier.close()` beside a wait that is starting.** By D189 the wait is a runtime error; a test with six waiters closed 1 ms after they announced themselves died in 2 of 9 runs. Recommended: a wait on a closed notifier returns at once, as a closed channel's `recv` gives `None`, and only a forged handle stays an error.
