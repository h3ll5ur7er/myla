title: Shadow Clone Jutsu
emoji: 🍥
tagline: Functions, recursion and closures. Believe it!

A ninja who can only throw one kunai is no ninja. Functions let you write a technique once and use it everywhere; recursion lets a function call a copy of itself, like a shadow clone summoning another.

- `fun name(a: int, b: str) -> int { … }` takes typed parameters and says what it returns.
- Every path through a function must `return` its value: Myla has no implicit last expression.
- A parameter may have a default: `fun jutsu(name: str, power: int = 9000)`.
- Functions are values: `(x: int) => x * 2` is a lambda of type `(int) -> int`.
