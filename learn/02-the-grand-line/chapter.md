title: The Grand Line
emoji: 🌊
tagline: if, while, for and match. Set sail for the most dangerous sea of all.

Every pirate who wants the One Piece must cross the Grand Line, and every programmer must cross control flow.

- `if cond { … } else if other { … } else { … }`: the condition must be a `bool`; there's no truthiness.
- `while cond { … }` loops while it holds; `for x in xs { … }` visits a list, and `for i in 0..n` counts from `0` to `n - 1`.
- `break` leaves a loop, `continue` goes on with the next round.
- `match` compares a value with patterns, and must cover every case.

See [[Language/Statements]] and [[Language/Structs-enums-and-match]]. Mind the Sea Kings.
